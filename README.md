# SkillSync

SkillSync is a campus-only skill discovery platform built for IIT Roorkee.

## Problem
Students struggle to discover skilled peers beyond informal networks. Genuine talent often remains hidden, and trust is hard to establish.

## Solution
SkillSync enables students to list any skill (academics, sports, arts, hobbies) and allows others to connect with them. Trust is built through real interactions, not self-claims.

## Key Features
- IITR-only authentication
- Skill discovery across all domains
- Interaction-based trust system
- Simple, scalable design

## Tech Stack
- React (Frontend)
- Firebase (Auth + Database)
